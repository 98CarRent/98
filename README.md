# 98CarRent 🚗

รถเช่ามุกดาหาร รถเช่าขับเอง รถเช่าพร้อมคนขับ — Car Rental Web App (Mukdahan & Nakhon Phanom, Thailand)

## Features
- 🚗 **Car Gallery** – each car shows Daily / Weekly / Monthly prices, with a **Book Now** button that opens contact info
- 🗺️ **Tourist Attractions** – Mukdahan & Nakhon Phanom with Google Maps location pins
- ⭐ **Customer Reviews** – add/edit/delete with star ratings
- 🎨 **Theme color picker** – change the site color scheme (saved to localStorage)
- 🌏 **Thai / English** – bilingual toggle
- 📱 Responsive – works on mobile and desktop
- 📝 Two pages: `index.html` (customer view) and `admin.html` (management panel)
- 💾 No database – all data stored in browser **localStorage**

## Pages
| Page | Description |
|------|-------------|
| `index.html` | Customer website (preview) |
| `admin.html` | Admin panel to manage cars, attractions, reviews |

## Run locally
Just open `index.html` in any browser. No server needed.
